Train Vehicle — Quick Start

Instructor

Setup

  1. 1 Layout the train track as desired and place the train on the track
  2. 2 Check the remote buttons are correct. Left buttons vertical with + up. Right buttons vertical with + up.
  3. 3 Press the hub button to turn on the the vehicle.
  4. 4 Press the hub button again to start the program. The hub light will first turn blue, then start flashing white — it is looking for the remote.
  5. 5 Turn on the remote by pressing its button. Once connected the vehicle homes itself (it moves to the corner of the End tile. Keep hands clear until it stops)
  6. 6 Hub flashes green — the vehicle is ready to start.

Running

Light What it looks like What it means
Blue — steady Program started, connecting…
3 white flashes, pause Looking for remote — wait
Green — flashing Ready — press buttons to start timer
Green — steady Timer running, vehicle working
Orange — steady Time’s up! Vehicle has stopped
Red — flashing Error — see troubleshooting below

To reset and run again: press left centre + centre + right centre buttons on the remote.

Troubleshooting

  • 🔄 Vehicle moving in the wrong direction Check remote button orientation is correct.
  • 🔋 Low battery — 5 red flashes Five red flashes means the battery is too low to run safely. Turn off the vehicle and swap or recharge the batteries before restarting.
  • 🟢 Remote not connecting — 4 red flashes Make sure the remote is turned on and nearby. Turn the vehicle off and back on to try again.
  • ⚠ Hub keeps flashing blue and won’t respond to button presses The program has been wiped from the hub (usually caused by very low batteries). The hub needs to be reprogrammed — find the event organiser.
