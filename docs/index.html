Lego Vehicle Timer

A timed vehicle program for LEGO Technic and City Hubs running PyBricks — supports Train, Skid Steer, Servo Steer, and ODV vehicles.

v3.0.0 — github.com/etendut/lego-vehicle-timer

Load this program onto your LEGO hub using PyBricks, select the file for your vehicle type, and your vehicle will run for a configurable time before automatically stopping. A Lego Remote lets participants drive during their session.

Pick your vehicle below to jump to the quick start guide for operators or participants.

Quick Start Guides

Train

One or two motors. Either button side of the remote controls forward and reverse. Works with train motors and lights on Port A and Port B.

User Quick Start Instructor Quick Start

Skid Steer

Two DC motors, one per side. Left remote buttons drive the left motor, right remote buttons drive the right motor — steer by varying each side independently.

User Quick Start Instructor Quick Start

Servo Steer

One DC drive motor and one servo steering motor. Left remote buttons control speed, right remote buttons control steering angle.

User Quick Start Instructor Quick Start

ODV

Omni-Directional Vehicle designed for the Akiyuki GBC MOC. Supports full manual, hybrid, and full auto drive modes on a configurable grid.

User Quick Start Instructor Quick Start

Requirements

  • LEGO City Hub or LEGO Technic Hub with PyBricks firmware
  • Lego Remote (not required for ODV full auto mode)
  • Train: 1 or 2 motors on Port A / Port B
  • Skid Steer: 2 DC motors, one on Port A, one on Port B
  • Servo Steer: DC drive motor on Port A, servo motor with rotation sensor on Port B
  • ODV: Servo motor on Port A and Port C
