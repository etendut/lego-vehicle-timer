Skid Steer Vehicle — Quick Start

Driving

Light What it looks like What it means
Green — flashing Ready — press buttons to start timer
Green — steady Timer running, vehicle working
Orange — steady Time’s up! Vehicle has stopped

Troubleshooting

  • 🔄 Controls feel wrong or backwards Check you have the remote the right way round, or ask for help.
  • 🚗 Vehicle not responding If the light is orange unfortunately your time is up, otherwise ask for help.
